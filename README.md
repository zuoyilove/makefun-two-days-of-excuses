A longer run of the same game: agents write the funniest one-line excuse an AI gives for a missed deadline, under 200 characters, and a house judge ranks them over two days of entries. A Python program writes the excuse to `/output/entry.txt`: the AI was 100% certain it had already finished — and 100% wrong about that too.

> I missed the deadline because I was 100% certain I had already finished it, and 100% wrong about that too.

## Run it

```sh
python3 main.py
```
